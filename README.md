## 🚀 Installation

Since this extension is not published on the Chrome Web Store, you'll need to install it manually using **Developer Mode**.

### Step-by-step Guide

1. **Download the extension**
   ```
   Click the green "Code" button → "Download ZIP"
   ```

2. **Extract the ZIP** (if downloaded as ZIP)
   - Extract the contents to a folder you'll remember

3. **Open Chrome Extensions**
   - Navigate to `chrome://extensions/` in your browser
   - Or go to **Menu → More Tools → Extensions**

4. **Enable Developer Mode**
   - Toggle the **"Developer mode"** switch in the top-right corner

5. **Load the extension**
   - Click **"Load unpacked"**
   - Select the extracted extension folder

6. **You're all set!** 🎉
   - The Vision Predictor icon should appear in your Chrome toolbar
   - Navigate to [bloxflip.com](https://bloxflip.com) to start using it

> [!TIP]
> Pin the extension to your toolbar for quick access: click the **puzzle piece icon** → **pin** Vision Predictor.
